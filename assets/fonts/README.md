# Fonts

Optional Hebrew font files can be placed in this folder.

Supported formats are `.woff2`, `.woff`, `.otf`, and `.ttf`. The template uses `Guttman Hatzvi` for Hebrew text. The generator will prefer a matching Guttman Hatzvi font file when present, then fall back to the first supported font file it finds. If no font is present, the template falls back to common Hebrew-capable system fonts.
